# Numarul Ereditar Karmic - Calcul

## Statutul formulei

Formula Numarului Neamului este preluata ca formula a Numarului Ereditar Karmic, denumire alternativa indicata explicit in nota legacy. Nu a fost lansat un audit formal nou.

## Formula de calcul

```text
numarul neamului = reducere_22(suma valorilor literelor din numele de familie)
```

```text
reducere_22(numar):
  cat timp numar > 22:
    numar = numar - 22
  return numar
```

### Asociere cu tarotul

- rezultatele 1-21 se citesc prin Arcanele Majore 1-21 din [[vault/Tarot/Index|tarot]];
- rezultatul 22 se citeste ca Arcana 0 - Nebunul din [[vault/Tarot/Index|tarot]].
