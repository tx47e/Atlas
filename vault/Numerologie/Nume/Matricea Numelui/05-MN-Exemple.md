# Matricea Numelui - Exemple

## Exemplu de calcul

Nume:

```text
ANA POPESCU
```

Valori:

```text
A=1, N=5, A=1, P=7, O=6, P=7, E=5, S=1, C=3, U=3
```

Componente:

```text
ANA = 1 + 5 + 1 = 7
POPESCU = 7 + 6 + 7 + 5 + 1 + 3 + 3 = 32 -> 5
numar de exprimare = 7 + 5 = 12 -> 3
codul numelui = 1517675133 + 3 = 15176751333
```
