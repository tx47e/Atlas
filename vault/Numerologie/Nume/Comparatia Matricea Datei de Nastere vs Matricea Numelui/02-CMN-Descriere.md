# Comparatia Matricea Datei de Nastere vs Matricea Numelui - Descriere

## Descriere

Matricea Numelui vs Matricea Datei de Nastere compara doua surse separate:

- [[vault/Numerologie/Matricea Datei de Nastere/Matricea Datei de Nastere/01-MDN-Index|Matricea Datei de Nastere]], care arata structura nativa;
- [[vault/Numerologie/Nume/Matricea Numelui/01-MN-Index|Matricea Numelui]], care arata ce activeaza numele.

Nu se calculeaza o a treia matrice. Comparatia se face pe fiecare casuta 1-9.

Aceasta comparatie face parte din capitolul extins [[vault/Numerologie/Nume/Influentele Numelui/01-IN-Index|Influentele Numelui]], alaturi de primele si ultimele litere, primele vocale, cheile de bolta si cifra energetica.

Aceasta rubrica nu este acelasi lucru cu [[vault/Numerologie/Nume/Matricea Numelui/01-MN-Index|Comparatia cu optimul]]. Comparatia cu optimul foloseste o matrice optima fixa si se documenteaza separat in [[vault/Numerologie/Nume/Matricea Numelui/01-MN-Index|Matricea Numelui]].
