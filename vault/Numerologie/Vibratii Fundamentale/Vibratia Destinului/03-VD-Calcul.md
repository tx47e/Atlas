# Vibratia Destinului - Calcul

## Prescurtări

```text
Vibratia Destinului = VD
Calea Destinului = CD
```

## Formula de calcul

```text
VD = reducere_numerologica(CD)
```

### Pași de calcul

1. Se calculează Calea Destinului și se notează valoarea completă CD.
2. Asupra valorii CD se aplică un singur proces de reducere numerologică.
3. În cadrul acestui proces, cifrele se adună succesiv până se obține o singură
   cifră.
4. Cifra finală obținută este VD.
5. Se păstrează traseul complet `CD → treaptă intermediară → VD`.

### Regula reducerii unice

Asupra lui CD se aplică o singură reducere numerologică, înțeleasă ca un proces
complet. Procesul continuă prin toate treptele necesare până la obținerea unei
singure cifre.

### Regula interpretării

Interpretarea se face atât pentru cifra finală VD, cât și pentru valorile
consemnate în traseul de reducere.

### Regula numerelor maestre

Dacă în traseul de reducere apare `11`, `22` sau `33`, numărul maestru se
consemnează și se interpretează în poziția în care apare. Reducerea continuă
până la cifra finală VD.
