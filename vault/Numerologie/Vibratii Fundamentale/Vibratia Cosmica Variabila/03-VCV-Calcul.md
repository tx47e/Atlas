# Vibratia Cosmica Variabila - Calcul

## Prescurtare

```text
Vibratia Cosmica Variabila = VCV
```

## Formula de calcul

```text
VCV = reducere_numerologica(ultimele doua cifre ale anului nasterii)
```

### Pași de calcul

1. Se preia anul nașterii în forma lui completă.
2. Se extrag ultimele două cifre, păstrând inclusiv zeroul inițial.
3. Se adună cifrele valorii extrase.
4. Dacă rezultatul rămâne compus, reducerea continuă până la `1-9`.
5. Se notează toate treptele.

### Regula de reducere

Traseul pornește de la ultimele două cifre ale anului și păstrează fiecare
valoare intermediară până la VCV.

### Regula numerelor maestre

Dacă valoarea extrasă sau o treaptă intermediară este `11`, `22` sau `33`,
numărul maestru se notează în traseu, apoi reducerea continuă până la cifra
finală.
