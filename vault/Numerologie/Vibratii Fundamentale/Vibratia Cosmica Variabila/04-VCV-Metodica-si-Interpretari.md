# Vibratia Cosmica Variabila - Metodica si interpretari

## Metodică

### 1. Anul complet

- Se păstrează anul nașterii cu toate cele patru cifre.
- Se diferențiază partea fixă de partea variabilă.

### 2. Extragerea componentei variabile

- Se extrag ultimele două cifre.
- Se păstrează ordinea și zeroul inițial, dacă apare.
- Valoarea extrasă este baza traseului VCV.

### 3. Numărul treptelor

- Se notează fiecare adunare a cifrelor.
- Se numără treptele reale ale reducerii.
- Traseul nu se comprimă la rezultatul final.

### 4. Cifrele componente

- Se identifică fiecare cifră a valorii extrase.
- Se urmărește contribuția fiecărei vibrații.
- Se păstrează ordinea cifrelor și valorile intermediare.

### 5. Compoziția elementelor

| Element | Cifre |
| --- | --- |
| Foc | `1`, `5`, `9` |
| Apă | `2`, `6` |
| Aer | `3`, `7` |
| Pământ | `4`, `8` |

- Se notează elementul fiecărei cifre.
- Se verifică elementele valorii extrase și ale treptelor compuse.
- Cifra `0` se consemnează separat.

### 6. Valorile intermediare și VCV

- Fiecare sumă compusă este păstrată ca treaptă.
- VCV este cifra finală a reducerii.
- VCV se citește împreună cu valoarea extrasă și traseul complet.

### 7. Numerele maestre

- Se verifică `11`, `22` și `33`.
- Se notează locul exact în traseu.
- Numărul maestru rămâne strat suplimentar, distinct de VCV finală.

### 8. Numărul `0`

- Se notează poziția lui `0`, inclusiv în valori precum `01`.
- Zeroul nu se elimină înaintea consemnării traseului.
- El nu este atribuit unui element.

### 9. Comparația cu VCF și VCT

- VCV se compară cu [[Vibratie Cosmica Fixa|VCF]].
- Se urmărește raportul dintre componenta activă și fundalul stabil.
- VCV se corelează apoi cu [[Vibratie Cosmica Totala|VCT]].

### 10. Lista de control

- ultimele două cifre sunt extrase corect;
- zeroul inițial este păstrat;
- toate treptele sunt afișate;
- cifrele și elementele sunt identificate;
- numerele maestre sunt marcate;
- VCV este distinctă de valorile intermediare;
- comparația cu VCF și VCT este pregătită.

## Interpretări

Interpretările se fac conform vibrației obținute. Dacă sunt predefinite în
directorul `VCV - Interpretari`, ele se preiau direct de acolo.
