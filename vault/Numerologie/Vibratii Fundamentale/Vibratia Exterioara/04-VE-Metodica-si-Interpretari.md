# Vibratia Exterioara - Metodica si interpretari

## Metodică

Înaintea interpretării se consemnează traseul complet al Vibrației Exterioare și
se verifică toate elementele de mai jos.

### 1. Luna nașterii ca valoare de plecare

- Se păstrează luna completă, între `1` și `12`.
- Se diferențiază luna directă, `1-9`, de luna compusă, `10-12`.
- Luna completă rămâne primul strat al citirii chiar dacă este redusă.

### 2. Numărul treptelor de reducere

- Lunile `1-9` nu au treaptă de reducere.
- Lunile `10`, `11` și `12` au o singură treaptă.
- Traseul nu se comprimă la cifra finală.

### 3. Cifrele lunii

- Se identifică fiecare cifră care alcătuiește luna.
- Se păstrează ordinea cifrelor.
- Se urmărește contribuția fiecărei vibrații la rezultatul final.
- Se notează separat apariția și poziția lui `0`.

### 4. Compoziția elementelor

| Element | Cifre |
| --- | --- |
| Foc | `1`, `5`, `9` |
| Apă | `2`, `6` |
| Aer | `3`, `7` |
| Pământ | `4`, `8` |

- Se notează elementul fiecărei cifre în ordinea apariției.
- Se observă dacă luna conține un singur element sau o combinație de elemente.
- Cifra `0` se consemnează separat și nu este atribuită unui element.
- Compoziția elementală rămâne distinctă de vibrația finală.

### 5. Vibrația finală

- Vibrația finală este cifra obținută după reducerea lunii.
- Ea se citește împreună cu luna completă și cu cifrele care o compun.
- O lună directă și o lună compusă care ajung la aceeași cifră nu sunt
  considerate automat identice.

### 6. Numerele maestre

- Se verifică dacă luna este `11`.
- Se notează că numărul maestru apare ca valoare de plecare.
- Vibrația `11` nu înlocuiește cifra finală `2`; ea constituie un strat
  suplimentar pentru interpretare.

### 7. Numărul `0`

- Se verifică prezența lui `0` în luna `10`.
- Poziția lui se păstrează în traseu.
- Rolul său interpretativ se stabilește în raport cu Vibrația `1`.

### 8. Traseul direct și traseul compus

- Se diferențiază Vibrația Exterioară directă de cea obținută prin reducere.
- Pentru lunile compuse se păstrează luna, cifrele ei și rezultatul final.
- Se compară traseele care ajung la aceeași vibrație finală.

### 9. Comparația dintre Vibrația Interioară și Vibrația Exterioară

După calcularea separată a celor două vibrații, Vibrația Exterioară se compară
obligatoriu cu [[vault/Numerologie/Vibratii Fundamentale/Vibratia Interioara/01-VI-Index|Vibrația Interioară]].

- Se notează valoarea finală a Vibrației Interioare.
- Se notează valoarea finală a Vibrației Exterioare.
- Se verifică dacă valorile sunt egale sau diferite.
- Dacă Vibrația Exterioară este egală cu Vibrația Interioară, egalitatea se
  evidențiază explicit.
- Egalitatea cifrei finale nu înseamnă automat trasee identice.
- În cazul egalității se compară luna și ziua de plecare, cifrele componente,
  numărul treptelor, compoziția elementală, numerele maestre și prezența lui
  `0`.
- Se diferențiază egalitatea directă de egalitatea obținută prin reducere.
- Dacă valorile sunt diferite, diferența se consemnează fără a fi declarată
  automat conflict; sensul ei se stabilește ulterior prin interpretare.
- Comparația interior-exterior se finalizează înaintea interpretării
  [[vault/Numerologie/Vibratii Fundamentale/Vibratia Globala/01-VG-Index|Vibrației Globale]].

### 10. Ordinea citirii

1. luna completă;
2. cifrele lunii, în ordinea lor;
3. elementul fiecărei cifre;
4. treapta de reducere, dacă există;
5. numărul maestru și poziția lui, dacă apare;
6. prezența și poziția lui `0`;
7. vibrația finală;
8. caracterul direct sau compus al traseului.

### 11. Delimitarea față de alte calcule

- Vibrația Exterioară se calculează din luna nașterii.
- Nu se confundă cu un calcul realizat din consoanele numelui.
- Corelarea cu [[vault/Numerologie/Vibratii Fundamentale/Vibratia Interioara/01-VI-Index|Vibrația Interioară]],
  [[vault/Numerologie/Vibratii Fundamentale/Vibratia Globala/01-VG-Index|Vibrația Globală]] și celelalte componente se face după
  finalizarea citirii proprii.

### 12. Lista de control pentru redactare

- luna de plecare este afișată;
- treapta reducerii este afișată, dacă există;
- cifrele lunii sunt identificate;
- compoziția elementală este consemnată;
- luna `11` este marcată ca număr maestru;
- prezența lui `0` este consemnată;
- vibrația finală este distinctă de valoarea de plecare;
- comparația cu Vibrația Interioară este consemnată;
- egalitatea dintre cele două vibrații este evidențiată, dacă apare;
- interpretarea diferențiază traseul direct de traseul compus.

## Interpretări

Interpretările se fac conform vibrației obținute. Dacă interpretările sunt
predefinite în directorul `VE - Interpretari` al Vibrației Exterioare, ele se preiau
direct de acolo.
