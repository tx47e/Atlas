# Vibratia Interioara - Calcul

## Prescurtare

```text
Vibratia Interioara = VI
```

## Formula de calcul

```text
VI = reducere_numerologica(ziua nasterii)
```

### Pasi de calcul

1. Se preia ziua din [[Datele de intrare|data nasterii]].
2. Daca ziua este intre 1 si 9, rezultatul este chiar ziua.
3. Daca ziua are doua cifre, se aduna cifrele intre ele.
4. Daca rezultatul are in continuare doua cifre, se reduce pana la 1-9.
5. Se noteaza toate treptele reducerii.

### Regula de reducere

Reducerea continua pana cand rezultatul este o singura cifra, intre 1 si 9.
Fiecare adunare a cifrelor reprezinta o treapta distincta si se noteaza in
ordinea in care apare.

### Regula numere maestre

Rezultatul final al calculului se reduce la 1-9. Daca ziua de nastere sau una
dintre treptele intermediare este `11`, `22` sau `33`, valoarea se noteaza in
traseu, apoi calculul continua pana la cifra finala.
