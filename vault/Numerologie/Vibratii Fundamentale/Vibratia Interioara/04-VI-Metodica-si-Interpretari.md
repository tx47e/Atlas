# Vibratia Interioara - Metodica si interpretari

## Metodică

Înaintea interpretării se consemnează traseul complet al Vibrației Interioare și
se verifică, în ordine, toate elementele de mai jos.

### 1. Ziua de naștere ca valoare de plecare

- Se păstrează ziua completă, între `1` și `31`.
- Se observă dacă valoarea este directă, formată dintr-o singură cifră, sau
  compusă, formată din două cifre.
- Ziua completă rămâne primul strat al citirii chiar dacă va fi redusă.

### 2. Numărul treptelor de reducere

- Fără treaptă: ziua este deja între `1` și `9`.
- O treaptă: cifrele zilei se adună și rezultatul este între `1` și `9`.
- Două trepte: prima adunare produce o valoare compusă, care trebuie redusă din
  nou.
- Se notează numărul exact al treptelor; nu se comprimă traseul direct la
  rezultatul final.

### 3. Cifrele din valoarea de plecare

- Se identifică fiecare cifră care alcătuiește ziua.
- Se păstrează ordinea cifrelor.
- Se urmărește contribuția fiecărei vibrații la formarea primei sume.
- Se verifică dacă una dintre cifre este `0` și poziția în care apare.

### 4. Compoziția elementelor

Pentru fiecare cifră din ziua de naștere se identifică elementul
corespunzător:

| Element | Cifre |
| --- | --- |
| Foc | `1`, `5`, `9` |
| Apă | `2`, `6` |
| Aer | `3`, `7` |
| Pământ | `4`, `8` |

- Se notează elementul fiecărei cifre în ordinea în care cifrele apar în zi.
- Se numără de câte ori apare fiecare element.
- Se observă dacă ziua este formată dintr-un singur element sau dintr-o
  combinație de elemente.
- Compoziția elementală a zilei se păstrează distinct de vibrația finală.
- Dacă traseul conține o valoare intermediară compusă, se verifică și
  compoziția elementală a cifrelor acelei trepte.
- Cifra `0` se consemnează separat; ea nu este atribuită unuia dintre cele
  patru elemente.

Pentru ziua `19`, traseul ajunge la Vibrația Interioară `1`, iar compoziția
zilei este:

```text
1 = Foc
9 = Foc
Compoziție: Foc + Foc
```

Pentru ziua `28`, traseul ajunge tot la Vibrația Interioară `1`, dar
compoziția zilei este:

```text
2 = Apă
8 = Pământ
Compoziție: Apă + Pământ
```

Prin urmare, rezultatul final identic nu anulează diferența dintre
compozițiile elementale ale zilelor de naștere.

### 5. Valorile intermediare

- Fiecare sumă obținută înaintea rezultatului final este o treaptă
  intermediară.
- Se notează valoarea întreagă a fiecărei trepte, nu numai cifrele ei.
- Se identifică vibrațiile care alcătuiesc treapta intermediară.
- Se urmărește ordinea în care treptele conduc spre vibrația finală.

### 6. Vibrația finală

- Vibrația finală este cifra obținută după încheierea reducerii.
- Ea se citește împreună cu ziua de plecare și cu toate valorile intermediare.
- Două zile care ajung la aceeași vibrație finală nu se consideră automat
  identice; se compară traseele lor.

### 7. Numerele maestre

- Se verifică dacă `11`, `22` sau `33` apare ca zi de plecare.
- Se verifică dacă un număr maestru apare într-o treaptă intermediară.
- Se notează locul exact în traseu: valoare de plecare sau rezultat
  intermediar.
- Numărul maestru nu înlocuiește cifra finală calculată; reprezintă un strat
  suplimentar care va fi integrat în interpretare.

### 8. Numărul `0`

- Se notează dacă `0` apare în ziua de plecare sau într-o treaptă intermediară.
- Se păstrează poziția lui în traseu.
- Nu se elimină înainte de efectuarea adunării.
- Rolul său interpretativ se stabilește numai în contextul cifrei sau al
  valorii alături de care apare.

### 9. Traseul direct și traseul compus

- Se diferențiază vibrația directă de vibrația obținută prin reducere.
- Pentru traseul compus se păstrează toate cifrele, sumele și pragurile.
- Se verifică dacă aceeași cifră finală provine din zile diferite și se
  evidențiază diferențele dintre trasee.

### 10. Comparația dintre Vibrația Interioară și Vibrația Exterioară

După calcularea separată a celor două vibrații, Vibrația Interioară se compară
obligatoriu cu [[Vibratie Exterioara|Vibrația Exterioară]].

- Se notează valoarea finală a Vibrației Interioare.
- Se notează valoarea finală a Vibrației Exterioare.
- Se verifică dacă valorile sunt egale sau diferite.
- Dacă Vibrația Interioară este egală cu Vibrația Exterioară, egalitatea se
  evidențiază explicit.
- Egalitatea cifrei finale nu înseamnă automat trasee identice.
- În cazul egalității se compară ziua și luna de plecare, cifrele componente,
  numărul treptelor, compoziția elementală, numerele maestre și prezența lui
  `0`.
- Se diferențiază egalitatea directă de egalitatea obținută prin reducere.
- Dacă valorile sunt diferite, diferența se consemnează fără a fi declarată
  automat conflict; sensul ei se stabilește ulterior prin interpretare.
- Comparația interior-exterior se finalizează înaintea interpretării
  [[Vibratie Globala|Vibrației Globale]].

### 11. Ordinea citirii

Citirea se pregătește în următoarea ordine:

1. ziua completă;
2. cifrele zilei, în ordinea lor;
3. elementul fiecărei cifre și compoziția elementală;
4. prima sumă;
5. eventualele sume intermediare și compoziția lor elementală;
6. numerele maestre întâlnite și poziția lor;
7. prezența și poziția lui `0`;
8. vibrația finală;
9. numărul total al treptelor de reducere.

### 12. Delimitarea față de alte calcule

- Vibrația Interioară se calculează din ziua nașterii.
- Nu se confundă cu [[Numarul Intim]], care aparține calculelor numelui.
- Corelarea cu [[Vibratie Exterioara|Vibrația Exterioară]],
  [[Vibratie Globala|Vibrația Globală]] și celelalte componente se face numai
  după finalizarea citirii proprii a Vibrației Interioare.

### 13. Lista de control pentru redactare

- ziua de plecare este afișată;
- toate treptele sunt afișate;
- numărul treptelor este corect;
- fiecare vibrație din traseu este identificată;
- compoziția elementală a zilei și a treptelor compuse este consemnată;
- numerele maestre sunt marcate cu poziția lor;
- prezența lui `0` este consemnată;
- vibrația finală este distinctă de treptele intermediare;
- comparația cu Vibrația Exterioară este consemnată;
- egalitatea dintre cele două vibrații este evidențiată, dacă apare;
- interpretarea nu reduce persoane cu trasee diferite la aceeași descriere.

## Interpretări

Interpretările se fac conform vibrației obținute. Dacă interpretările sunt
predefinite în directorul `VI - Interpretari` al Vibrației Interioare, ele se preiau
direct de acolo.
