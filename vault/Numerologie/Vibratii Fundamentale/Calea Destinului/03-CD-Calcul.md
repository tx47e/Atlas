# Calea Destinului - Calcul

## Prescurtare

```text
Calea Destinului = CD
```

## Formula de calcul

```text
CD = suma tuturor cifrelor din data nasterii
```

Rezultatul se pastreaza ca numar compus si nu se reduce complet in cadrul
acestui calcul.

### Pasi de calcul

1. Se scrie data nasterii in forma `ZZLLAAAA`.
2. Se aduna toate cifrele datei.
3. Rezultatul obtinut se pastreaza ca valoare completa CD.
4. Orice rezultat derivat din CD se calculeaza separat, conform regulii
   confirmate in [[Registru Validare Formule]].

### Interval

- Valoarea minima posibila este `4`.
- Valoarea maxima posibila este `48`.
- Pentru valorile `4-9`, in interpretare se considera un `0` implicit in fata.

## Regula de separare

CD ramane valoarea completa obtinuta direct din data nasterii. Acest modul se
opreste la CD si nu redefineste calculul [[Vibratia Destinului|Vibratiei
Destinului]], al Destinului sau al cifrei suplimentare de interpretare.

Aceste rezultate dependente se pastreaza distincte si se verifica in
[[Registru Validare Formule]].
