# Calea Destinului - Descriere

## Descriere

Calea Destinului este suma tuturor cifrelor din data nasterii din datele de intrare, pastrata ca valoare completa inaintea calculelor dependente.

In bibliografia de lucru, aceasta rubrica apare si ca vibratia Caii Destinului. In proiect, cele doua denumiri sunt echivalente.

Calea Destinului povesteste despre ce si cum are de facut omul prin viata, ca sa isi realizeze destinul.

- prima cifra raspunde la intrebarea `CE?`;
- a doua cifra raspunde la intrebarea `CUM?`.

Daca se obtine un numar format dintr-o singura cifra, aceasta raspunde la ambele
intrebari.

## Delimitare

Calea Destinului pastreaza suma completa a cifrelor din data nasterii. Acest
concept nu stabileste formula rezultatului derivat si nu se confunda cu
[[Vibratia Destinului]] sau cu cifra suplimentara de interpretare.

Formula conceptelor dependente se verifica separat in
[[Registru Validare Formule]].
