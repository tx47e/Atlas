# Calea Destinului - Exemple

## Exemplul 1

Date initiale:

- Data nasterii: `24.04.1982`.

Data numerica:

```text
24041982
```

Calcul:

```text
2 + 4 + 0 + 4 + 1 + 9 + 8 + 2 = 30
```

Rezultat:

```text
CD = 30
```

Interpretare scurta:

- cifra `3` raspunde la intrebarea `ce?`: exprimare, comunicare, creativitate
  si transmitere;
- cifra `0` raspunde la intrebarea `cum?`: prin potential, deschidere, credinta
  si un camp mai larg de constienta.

## Exemplul 2

Date initiale:

- Data nasterii: `17.04.1984`.

Calcul:

```text
1 + 7 + 0 + 4 + 1 + 9 + 8 + 4 = 34
```

Rezultat:

```text
CD = 34
```

Interpretare scurta:

- cifra `3` arata ce are persoana de cultivat: comunicare, expresie si
  capacitatea de a da forma vie experientei;
- cifra `4` arata cum: prin disciplina, structura, rabdare si constructie pas
  cu pas.
