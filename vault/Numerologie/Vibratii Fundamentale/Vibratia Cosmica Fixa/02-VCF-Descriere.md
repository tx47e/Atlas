# Vibratia Cosmica Fixa - Descriere

## Descriere

Vibrația Cosmică Fixă este componenta constantă a [[Vibratie Cosmica Totala|Vibrației Cosmice]]. Ea provine din primele două cifre ale anului nașterii și descrie fundalul subtil, generațional și greu de schimbat al persoanei.

În acest proiect, Vibrația Cosmică Fixă se păstrează ca valoare de context.
Rolul ei este să arate planul stabil din care se naște experiența persoanei.

Pentru anii `1900`, componenta fixă este `19`. Pentru anii `2000`, componenta
fixă este `20`. Diferența se citește ca schimbare de fundal colectiv, nu ca
trăsătură individuală izolată.
