# Aspecte de Indreptat si Solutia - Metodica si interpretari

## Metodica

Aspectele de Indreptat si Solutia se calculeaza si se afiseaza separat, apoi se
interpreteaza impreuna.

### 1. Datele de plecare

- data completa de nastere;
- Calea Destinului completa;
- ziua de nastere;
- prima cifra din ziua de nastere.

### 2. Calculul Aspectelor

- se aplica formula `AI = CD - 2 x PZ`;
- se pastreaza rezultatul complet AI;
- se afiseaza toate operatiile.

### 3. Interpretarea Aspectelor

Numarul compus AI reprezinta materialul de lucru. Cifrele lui se citesc separat
ca zone care trebuie observate, reparate sau corectate.

Interpretarea foloseste documentatia completa a fiecarei vibratii componente,
in special:

- fisierul `Lumina`, pentru potentialul care poate fi recuperat;
- fisierul `Umbra`, pentru manifestarile care trebuie indreptate;
- fisierul `Lectii`, pentru procesul de invatare;
- fisierul `Dezvoltare`, pentru directiile practice.

### 4. Calculul Solutiei

Solutia se calculeaza din cifrele AI. Pana la aprobarea alinierii formulei, se
consemneaza explicit metoda folosita:

- reducere repetata pana la o singura cifra; sau
- o singura insumare a cifrelor, cu pastrarea rezultatului compus.

Metodele nu se combina si nu se prezinta ca fiind echivalente.

### 5. Interpretarea Solutiei

Solutia arata energia prin care Aspectele pot fi indreptate. Interpretarea ei nu
inlocuieste interpretarea cifrelor componente ale AI.

Daca Solutia ramane un numar compus, valoarea compusa se pastreaza, iar cifrele
ei se interpreteaza fara a ascunde traseul de calcul.

### 6. Ordinea citirii

1. CD;
2. PZ;
3. formula completa AI;
4. rezultatul AI;
5. cifrele componente ale AI;
6. metoda folosita pentru SAI;
7. rezultatul SAI;
8. relatia dintre Aspecte si Solutie;
9. recomandarea practica.

### 7. Lista de control

- CD este pastrata ca valoare completa;
- PZ este prima cifra a zilei, nu Vibratia Interioara;
- AI este afisat distinct;
- cifrele AI sunt interpretate separat;
- metoda de calcul SAI este declarata;
- rezultatul SAI nu este redus suplimentar fara o regula aprobata;
- Aspectele si Solutia sunt interpretate impreuna;
- discrepanta de formula nu este ascunsa.
