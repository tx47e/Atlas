# Aspecte de Indreptat si Solutia - Exemple

## Exemplul din nota legacy

Date initiale:

- data nasterii: `03.02.1980`;
- CD = `23`;
- PZ = `3`.

Calcul AI:

```text
AI = 23 - 2 x 3
AI = 23 - 6
AI = 17
```

Interpretare:

- Aspectele de Indreptat sunt `17`;
- se citesc separat Vibratia `1` si Vibratia `7`.

Calculul Solutiei:

```text
1 + 7 = 8
```

Rezultat:

- SAI = `8`.

Acest exemplu nu diferentiaza cele doua metode aflate in audit, deoarece ambele
produc rezultatul `8`.

## Cazuri de control ale auditului

Aceste cazuri sunt consemnate pentru validarea formulei si nu reprezinta o
corectie implementata prin acest document.

| AI | O singura insumare | Reducere repetata |
| ---: | ---: | ---: |
| `37` | `10` | `1` |
| `29` | `11` | `2` |

Valorile `37 -> 10` si `29 -> 11` sunt cazurile care disting metodele si necesita
aprobarea separata a alinierii.
