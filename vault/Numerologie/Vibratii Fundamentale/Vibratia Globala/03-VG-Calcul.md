# Vibratia Globala - Calcul

## Prescurtare

```text
Vibratia Globala = VG
```

## Formula de calcul

```text
VG = reducere_numerologica(VI + VE)
```

### Pași de calcul

1. Se calculează [[vault/Numerologie/Vibratii Fundamentale/Vibratia Interioara/01-VI-Index|Vibrația Interioară]].
2. Se calculează [[vault/Numerologie/Vibratii Fundamentale/Vibratia Exterioara/01-VE-Index|Vibrația Exterioară]].
3. Se adună rezultatul VI cu rezultatul VE.
4. Suma se reduce numerologic până la o singură cifră, între `1` și `9`.
5. Se notează traseul `VI + VE`, suma și toate treptele reducerii.

### Regula de reducere

Fiecare adunare a cifrelor reprezintă o treaptă distinctă. Traseul pornește de
la rezultatele VI și VE, continuă cu suma lor și păstrează toate valorile
intermediare până la vibrația finală.

### Regula numerelor maestre

Dacă suma VI + VE sau una dintre treptele intermediare este `11`, `22` sau
`33`, valoarea se notează în traseu, apoi reducerea continuă până la cifra
finală.
