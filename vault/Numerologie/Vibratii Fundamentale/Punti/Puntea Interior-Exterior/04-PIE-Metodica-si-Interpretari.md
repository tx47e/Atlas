# Puntea Interior - Exterior - Metodica si interpretari

## Metodica

1. Se interpreteaza VI ca lume interioara.
2. Se interpreteaza VE ca expresie si rol vizibil.
3. Se calculeaza PIE.
4. Rezultatul se citeste ca energie de integrare.
5. Se explica modul concret in care persoana poate armoniza interiorul cu
   exteriorul.

## Rezultatul zero

Daca `VI = VE`, atunci `PIE = 0`. Cele doua zone sunt pe aceeasi frecventa si
nu exista o punte de trecut. Interpretarea descrie sustinerea directa dintre
interior si exterior.

## Lista de control

- VI si VE sunt afisate separat;
- calculul cu valoare absoluta este vizibil;
- rezultatul nu inlocuieste valorile comparate;
- interpretarea leaga explicit lumea interioara de rolul exterior;
- rezultatul `0` este tratat ca egalitate, nu ca lipsa de continut.
