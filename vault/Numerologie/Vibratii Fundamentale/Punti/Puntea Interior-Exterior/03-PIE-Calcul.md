# Puntea Interior - Exterior - Calcul

## Prescurtari

```text
Vibratia Interioara = VI
Vibratia Exterioara = VE
Puntea Interior - Exterior = PIE
```

## Formula

```text
PIE = |VI - VE|
```

## Pasi de calcul

1. Se calculeaza VI.
2. Se calculeaza VE.
3. Se scade o valoare din cealalta.
4. Se pastreaza valoarea absoluta a diferentei.
5. Rezultatul se interpreteaza conform [[02-PU-Reguli-Comune|regulilor comune]].
