# Puntea Exterior - Destin - Metodica si interpretari

## Metodica

1. Se consemneaza VE.
2. Se consemneaza separat Calea Destinului, Destinul compus si cifra lui de
   interpretare.
3. In formula se foloseste numai cifra de interpretare.
4. Se calculeaza diferenta absoluta.
5. Rezultatul se citeste ca energie de integrare intre expresia exterioara si
   directia de destin.

## Lista de control

- VE este afisata;
- Destinul compus nu este introdus direct in formula;
- cifra de interpretare este afisata distinct;
- calculul cu valoare absoluta este vizibil;
- interpretarea nu confunda puntea cu valorile de plecare.
