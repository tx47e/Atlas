# Puntea Cosmic - Destin - Calcul

## Prescurtari

```text
Vibratia Cosmica Totala = VCT
Cifra de interpretare a Destinului = CID
Puntea Cosmic - Destin = PCD
```

## Formula

```text
PCD = |VCT - CID|
```

## Regula Destinului compus

Cand Destinul este compus, formula foloseste cifra suplimentara de interpretare,
nu valoarea compusa.

```text
Calea Destinului 39 -> Destin 12 -> cifra de interpretare 3
PCD = |VCT - 3|
```

## Statut

Formula este documentata in [[vault/Numerologie/Vibratii Fundamentale/Punti/01-PU-Index|Punti]] si este compatibila cu regula Destinului
din [[Registru Validare Formule]]. Nu a fost identificata o implementare
dedicata in calculatorul agregat in inventarul curent.
