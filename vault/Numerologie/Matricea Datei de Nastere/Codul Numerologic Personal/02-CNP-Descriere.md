# Codul Numerologic Personal - Descriere

## Descriere

Codul numerologic personal este sirul complet de cifre folosit pentru construirea [[vault/Numerologie/Matricea Datei de Nastere/Matricea Datei de Nastere/01-MDN-Index|matricei datei de nastere]].

El nu este un calcul separat de [[vault/Numerologie/Matricea Datei de Nastere/Matricea Datei de Nastere/01-MDN-Index|Matricea Datei de Nastere]]. Este denumirea operationala pentru:

```text
data nasterii + N1 + N2 + N3 + N4
```

Daca proiectul prefera sa pastreze mai putine note, acest concept poate fi sters, iar informatia ramane in [[vault/Numerologie/Matricea Datei de Nastere/Matricea Datei de Nastere/01-MDN-Index|Matricea Datei de Nastere]].
