# Temperament - Exemple

## Exemplu de calcul

Pentru matricea exemplului `24.04.1982`:

```text
Foc = 1 + 0 + 1 = 2
Aer = 2 + 0 = 2
Apa = 3 + 1 = 4
Pamant = 2 + 2 = 4
```

Apa si Pamant au cele mai mari totaluri. Temperamentul predominant este mixt,
flegmatic-melancolic. Focul si Aerul sunt prezente egal, dar mai discret.
