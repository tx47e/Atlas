# Ani Importanti Interior si Exterior - Exemple

## Exemplu de calcul

### Exemplu ani interiori

Pentru anul nasterii 1988:

```text
1988: 1 + 9 + 8 + 8 = 26 -> 8
1988 + 8 = 1996

1996: 1 + 9 + 9 + 6 = 25 -> 7
1996 + 7 = 2003

2003: 2 + 0 + 0 + 3 = 5
2003 + 5 = 2008
```

Ani importanti interiori:

- 1996;
- 2003;
- 2008.

### Exemplu ani exteriori

Pentru anul nasterii 1988:

```text
1988: 1 + 9 + 8 + 8 = 26
1988 + 26 = 2014

2014: 2 + 0 + 1 + 4 = 7
2014 + 7 = 2021

2021: 2 + 0 + 2 + 1 = 5
2021 + 5 = 2026
```

Ani importanti exteriori:

- 2014;
- 2021;
- 2026.

```text

```

```text
Ani importanti interiori in interval: 2023, 2030, 2035, 2036
```
